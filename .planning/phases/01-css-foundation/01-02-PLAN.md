    ```scss
    // _typography.scss
    // Handles link behavior and any element overrides not covered by Bootstrap $variables.
    // Font family (Inter stack) and heading weights flow through _variables.scss at compile time.

    // Link decoration override for dark surfaces.
    // Dark surfaces use color alone as the link affordance — no underline by default.
    // Underline restores on hover for accessibility.

      text-decoration: none;

      &:hover {
        text-decoration: underline;
      }
    }
    ```
