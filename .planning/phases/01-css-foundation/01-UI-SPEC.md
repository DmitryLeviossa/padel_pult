# Phase 1 — UI Design Contract

> Visual and interaction contract for the CSS Foundation phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This phase is a CSS token/foundation layer only — no UI components are rendered to end users in this phase. The contract defines the exact token values, file structure, and Bootstrap override wiring that all subsequent phases (2–5) depend on.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | Bootstrap 5.3.3 (existing — override layer only, no new components in this phase) |
| Icon library | Bootstrap Icons (already installed via yarn, imported via `bootstrap-icons/font/bootstrap-icons`) |
| Font | Inter (Google Fonts `<link>` in layout head) with system fallback: `'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif` |

Font loading decision rationale: Inter is the exact font used by Linear.app (the design reference). It is free via Google Fonts — no licensing cost. System fonts render Inter on macOS/iOS automatically; the explicit Google Fonts import guarantees Inter on other platforms.

### 60 / 30 / 10 Color Distribution

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `--color-bg-base` | `#0d1117` | Page body, all non-elevated backgrounds |
| Secondary (30%) | `--color-bg-navbar` + `--color-bg-surface` | `#161b22` / `#21262d` | Navbar, cards, panels, modal backgrounds |
| Accent (10%) | `--color-accent` | `#2f81f7` | See reserved list below |

Accent (`#2f81f7`) reserved for:
- Primary button background (`.btn-primary`)
- Focus rings on inputs and interactive elements
- Active navigation link indicator
- Hyperlinks (`<a>` color)
- Button hover glow (Phase 5: `box-shadow: 0 0 12px rgba(47,129,247,0.3)`)

Destructive color (`--color-danger: #f85149`) reserved for:
- Delete / remove confirmation dialogs
- Form validation error messages
- Destructive alert states

## Spacing Scale

Token naming follows `--space-{N}` with `0.25rem` (4px) base unit matching Bootstrap's spacing scale.

| Token | Value (rem) | Value (px) | Usage |
|-------|-------------|------------|-------|
| `--space-1` | `0.25rem` | 4px | Icon gaps, inline micro-padding |
| `--space-2` | `0.5rem` | 8px | Compact element spacing, badge padding |
| `--space-3` | `0.75rem` | 12px | Tight list item padding |
| `--space-4` | `1rem` | 16px | Default element spacing (base unit) |
| `--space-5` | `1.25rem` | 20px | Form field spacing |
| `--space-6` | `1.5rem` | 24px | Section padding, card body |
| `--space-7` | `1.75rem` | 28px | Large card padding |
| `--space-8` | `2rem` | 32px | Layout gaps, major section breaks |

Extended tokens for page-level layout (beyond the `--space-{1..8}` series):

| Token | Value (rem) | Value (px) | Usage |
|-------|-------------|------------|-------|
| `--space-12` | `3rem` | 48px | Major section breaks |
| `--space-16` | `4rem` | 64px | Page-level vertical rhythm |

Exceptions: Touch targets minimum 44px (applies to interactive elements in Phases 2+, not this phase).

## Typography

Font stack: `'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif`

Bootstrap SCSS variable: `$font-family-sans-serif: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif`

| Role | Size (rem) | Size (px) | Weight | Line Height | Bootstrap mapping |
|------|------------|-----------|--------|-------------|-------------------|
| Body | `0.9375rem` | 15px | 400 (regular) | 1.5 | `$font-size-base` |
| Label / Muted | `0.875rem` | 14px | 400 (regular) | 1.4 | `$small-font-size: 0.875em` |
| Heading (h4–h6) | `1rem–1.25rem` | 16–20px | 600 (semibold) | 1.3 | `$headings-font-weight: 600` |
| Heading (h1–h3) | `1.5rem–2rem` | 24–32px | 600 (semibold) | 1.2 | `$headings-font-weight: 600` |

Exact heading sizes (Bootstrap's default modular scale, kept as-is):

| Element | Size (rem) | Size (px) |
|---------|------------|-----------|
| `h1` | `2rem` | 32px |
| `h2` | `1.75rem` | 28px (Bootstrap default: 1.5rem → use Bootstrap default) |
| `h3` | `1.5rem` | 24px |
| `h4` | `1.25rem` | 20px |
| `h5` | `1rem` | 16px (same as body — differentiated by weight) |
| `h6` | `0.9375rem` | 15px (same as body — differentiated by weight + uppercase in Phase 5) |

Weights declared (exactly 2):
- `400` — regular: body text, labels, muted text
- `600` — semibold: headings, button labels, table headers (Phase 5), nav links

Link color: `var(--color-accent)` — `#2f81f7`. Hover: `var(--color-accent-hover)` — `#4d94f8`. No underline by default on dark surfaces.

## SCSS File Structure

Entry point: `app/assets/stylesheets/application.bootstrap.scss` (rewritten from current 2-line file)

```
app/assets/stylesheets/
├── application.bootstrap.scss   # Pure import manifest — no rules here
├── _variables.scss              # Bootstrap SCSS variable overrides (before Bootstrap imports)
├── _theme.scss                  # :root { --color-* } + [data-bs-theme="dark"] { --bs-* overrides }
├── _spacing.scss                # :root { --space-* } tokens
└── _typography.scss             # font-family on body, heading weight/size overrides, link styles
```

Import order in `application.bootstrap.scss`:
1. `bootstrap/scss/functions` (required before color manipulation)
2. `variables` (project overrides — before Bootstrap's own variables)
3. `bootstrap/scss/variables`
4. `bootstrap/scss/variables-dark`
5. `bootstrap/scss/maps`
6. `bootstrap/scss/mixins`
7. `bootstrap/scss/root`
8. Bootstrap component partials (utilities, reboot, type, grid, containers, helpers, buttons, nav, navbar, card, forms, modal, dropdown, badge, alert, tables, transitions, spinners, utilities/api)
9. `theme` (`:root` tokens + `[data-bs-theme="dark"]` overrides)
10. `spacing` (`--space-*` tokens)
11. `typography` (font-family, heading styles, link overrides)
12. `bootstrap-icons/font/bootstrap-icons`

Layout change required (not a CSS file change — a Slim template change): `<html data-bs-theme="dark">` on the `<html>` element in `app/views/layouts/application.html.slim`. This activates Bootstrap's dark mode CSS variable layer.

## Copywriting Contract

This phase has no rendered UI — no user-facing copy is produced in Phase 1. The copywriting contract entries below are defined here as the canonical source for downstream phases.

| Element | Copy |
|---------|------|
| Primary CTA | "Save changes" (forms), "Create [noun]" (creation actions) — finalized per page in Phase 4 |
| Empty state heading | "No [noun] yet" — e.g. "No leagues yet", "No tournaments yet" |
| Empty state body | "Create your first [noun] to get started." |
| Error state | "[What failed]. [What to do next]." — e.g. "Something went wrong. Try again or contact support." |
| Destructive confirmation | "Delete [noun]" → confirmation: "This cannot be undone. Delete [noun]?" |

Copy decisions for specific pages deferred to Phase 4 (Content Pages). The patterns above are the contract format.
