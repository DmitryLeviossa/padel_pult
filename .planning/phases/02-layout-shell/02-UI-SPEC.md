## Component Contracts

### LAY-01: Navbar (`_navbar.html.slim` + `_navbar.scss`)

**HTML structure:** Bootstrap `navbar-expand-lg` — collapses to hamburger below `lg` breakpoint (992px)

**Surface:**
- Background: `var(--color-bg-navbar)` — `#161b22` — via `_navbar.scss` (NOT `.bg-dark` which maps to `#21262d`)
- Bottom border: `1px solid var(--color-border)` — `#30363d`
- No box-shadow

**Brand:**
- Text: "Padel Pult"
- Color default: `var(--color-text-primary)` — `#e6edf3`
- Color hover: `var(--color-accent-hover)` — `#4d94f8`
- Weight: 600 (semibold)
- Class: `.navbar-brand.fw-semibold`
- No underline on hover (`.navbar-brand` excluded from `_typography.scss` rule)

**Nav links (desktop):**
- Default color: `var(--color-text-muted)` — `#8b949e`
- Hover color: `var(--color-text-primary)` — `#e6edf3`
- Hover background: `rgba(255, 255, 255, 0.05)` — subtle ghost fill
- Active color: `var(--color-accent)` — `#2f81f7`
- Active weight: 600 (semibold)
- Transition: `color 0.15s ease-in-out, background-color 0.15s ease-in-out`
- Padding: `var(--space-2) var(--space-3)` → `8px 12px`
- Border radius: `var(--bs-border-radius-sm)` → `0.25rem`
- Active detection: `request.path.start_with?('/leagues')` pattern (section-level), not exact `current_page?`

**Nav links shown when:** `user_signed_in?` is true
- Лиги → `leagues_path`
- Турниры → `tournaments_path`
- Игроки → `users_path`

**User avatar (signed-in state):**
- Type: Initials-only circle (no photo in Phase 2)
- Shape: circle — `border-radius: 50%`
- Size: 32x32px
- Background: `var(--color-bg-surface)` — `#21262d`
- Border: `1px solid var(--color-border)` — `#30363d`
- Text: first letter of each word in `current_user.full_name`, max 2 chars, upcased
- Font: 0.75rem (12px), weight 600
- Text color: `var(--color-text-muted)` — `#8b949e`
- Trigger: Bootstrap dropdown toggle (`data-bs-toggle="dropdown"`)

**User dropdown menu:**
- Background: `var(--color-bg-surface)` — `#21262d` (via `--bs-dropdown-bg` already set in `_theme.scss`)
- Border: `1px solid var(--color-border)` (via Bootstrap dark theme)
- Alignment: `.dropdown-menu-end` (right-aligned)
- Items: "Редактировать аккаунт" → `edit_user_registration_path`; divider; "Выйти" button
- "Выйти" item color: `var(--color-danger)` — `#f85149` via `.text-danger`
- "Выйти" implementation: `button_to` with `method: :delete` (CSRF-safe)
- No `.dropdown-menu-dark` class needed — `data-bs-theme="dark"` on `<html>` covers this

**Signed-out state (navbar right side):**
- "Войти" link — `.nav-link` default style
- "Регистрация" button — `.btn.btn-primary.btn-sm.ms-2`

**Hamburger toggler (mobile — below 992px):**
- Element: `.navbar-toggler` Bootstrap class
- Icon: `.navbar-toggler-icon` SVG — rendered correctly by Bootstrap with `data-bs-theme="dark"` on `<html>`
- Border: `1px solid var(--color-border)`
- Focus ring: `box-shadow: 0 0 0 0.25rem rgba(47, 129, 247, 0.25)` (accent, 25% opacity)
- Touch target: minimum 44x44px (Bootstrap default padding ensures this)
- `aria-label="Toggle navigation"`, `aria-controls="navbarCollapse"`, `aria-expanded="false"` initially
- Wired to Stimulus: `data-action="navbar#toggle"` (NO `data-bs-toggle="collapse"` — Stimulus owns the trigger)

**Collapse behavior (mobile):**
- Collapse target ID: `navbarCollapse`
- Target attributes: `data-navbar-target="menu"`, `id="navbarCollapse"`, `.collapse.navbar-collapse`
- Animation: Bootstrap Collapse plugin CSS transition (`height: 0 → auto`) — delegated to Bootstrap
- Mobile nav links: stack vertically, full-width, same color rules as desktop

**Stimulus navbar controller:**
- File: `app/javascript/controllers/navbar_controller.js`
- Controller name: `navbar`
- `data-controller="navbar"` on `<nav>` element
- `static targets = ["menu"]`
- `toggle()` method calls `Collapse.getOrCreateInstance(this.menuTarget).toggle()`
- Import: `import { Collapse } from "bootstrap"` (named import from importmap pin)

### LAY-02: Flash Messages (`_flash.html.slim` + `_flash.scss` + `flash_controller.js`)

**Position:** Directly below navbar, above `<main>` — rendered via `= render "layouts/flash"` in `application.html.slim`

**Width:** Full viewport width (no container constraint at flash level) — same as navbar

**Margin:** No margin between navbar and flash; flash items have `mb-0` between them (Bootstrap default `alert` has `mb-3`, remove with `mb-2`)

**Per-flash-type alert class mapping:**

| Flash key | Bootstrap class | Semantic color |
|-----------|-----------------|----------------|
| `notice` | `alert-success` | `--color-success` (#3fb950) tint |
| `alert` | `alert-danger` | `--color-danger` (#f85149) tint |
| `warning` | `alert-warning` | `--color-warning` (#d29922) tint |
| `info` | `alert-info` | Bootstrap info tint |
| *(any other)* | `alert-secondary` | Bootstrap secondary tint |

Bootstrap alert dark variants are automatic via `data-bs-theme="dark"` on `<html>` — no custom dark CSS needed for alert backgrounds.

**Alert structure:**
- Classes: `.alert.alert-dismissible.fade.show` + flash-type class
- `role="alert"` for accessibility
- `data-controller="flash"` for auto-dismiss
- `data-flash-delay-value="5000"` (5 seconds)
- `data-turbo-temporary` attribute to exclude from Turbo snapshot cache (prevents reappearance on back-navigation)

**Dismiss button:**
- Class: `.btn-close`
- `type="button"`
- `data-bs-dismiss="alert"` — Bootstrap handles the CSS fade-out transition
- `data-action="flash#close"` — Stimulus also handles immediate removal on manual close
- `aria-label="Close"`

**Auto-dismiss:**
- Delay: 5000ms (5 seconds) — set via `data-flash-delay-value`
- Mechanism: `setTimeout(() => this.close(), this.delayValue)` in Stimulus `connect()`
- Timer cleared on `disconnect()` to prevent errors on Turbo navigation

**Close animation:**
- Remove `.show` class → Bootstrap `.fade` transition plays (opacity 0 over 150ms)
- `transitionend` event → `element.remove()` (once listener)
- Fallback if `transitionend` fires unexpectedly: element still removed

**Stimulus flash controller:**
- File: `app/javascript/controllers/flash_controller.js`
- Controller name: `flash`
- `static values = { delay: { type: Number, default: 5000 } }`
- `connect()`: sets `this.timer = setTimeout(() => this.close(), this.delayValue)`
- `disconnect()`: calls `clearTimeout(this.timer)`
- `close()`: removes `.show`, adds `transitionend` once-listener that calls `this.element.remove()`

**Cleanup required:** Remove inline flash blocks from `dashboard/index.html.slim` lines 4-7 and `leagues/index.html.slim` lines 6-7 after adding layout partial.

### LAY-03: Page Body Background (`application.html.slim` + existing `_theme.scss`)

**Body background:** `#0d1117` (`--color-bg-base`) — already applied via `$body-bg` Bootstrap SCSS override and `--bs-body-bg` CSS variable in `_theme.scss`. No new CSS needed.

**Visual layering (back to front):**
1. `<body>` / `<html>` — `#0d1117` (`--color-bg-base`) — darkest layer
2. Navbar surface — `#161b22` (`--color-bg-navbar`) — mid dark layer, 1px border separating from body
3. Cards / dropdowns / inputs — `#21262d` (`--color-bg-surface`) — lightest layer

**Main content wrapper:**
- Element: `<main class="py-4">`
- Padding: Bootstrap `py-4` = `1.5rem` top and bottom (24px)
- No `.container` class on `<main>` — pages provide their own container constraints
- Background: inherits `--color-bg-base` from body — no explicit background needed
- No `min-height` constraint in this phase

### LAY-04: Mobile Hamburger (Stimulus + Bootstrap Collapse)

Fully specified in LAY-01 Navbar section above. Summary:

**Breakpoint:** 992px (`lg`) — hamburger visible below, full nav visible at 992px+
**Collapse ID:** `navbarCollapse`
**Toggle owner:** Stimulus `navbar_controller.js` — NOT Bootstrap `data-bs-toggle` attribute
**Animation:** Bootstrap Collapse CSS transition — height 0 to auto
**Overlay vs push:** Push behavior (nav links expand below brand row, pushing page content down) — Bootstrap default
**No backdrop or overlay needed** in Phase 2
