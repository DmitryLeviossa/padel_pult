## Motion / Interactions

All transitions use `$transition-base: all 0.15s ease-in-out` — already defined in `_variables.scss`. No new timing values are introduced.

### POLL-01 — Button Hover Glow

| Property | Value |
|----------|-------|
| Selector | `.btn-primary:hover, .btn-primary:focus-visible, .btn-accent:hover, .btn-accent:focus-visible` |
| Property changed | `box-shadow` |
| Hover value | `0 0 12px rgba(47,129,247,0.3)` |
| Default value | `none` (or Bootstrap's existing focus shadow — see note) |
| Transition | `$transition-base` (0.15s ease-in-out) |
| Layout shift | none — box-shadow does not affect layout flow |
| Constraint | Do NOT change `padding`, `border-width`, or `margin` on hover |

Note: Bootstrap's `.btn-primary` already has a focus-visible shadow via `$btn-focus-box-shadow`. The glow must be additive or replace it cleanly — use `box-shadow: 0 0 12px rgba(47,129,247,0.3)` on `:hover` and confirm `:focus-visible` also receives the glow for accessibility.

Implementation target: new `_interactions.scss` partial, imported at end of `application.bootstrap.scss` after `@import 'avatar'`.

### POLL-02 — Clickable Card Hover Lift

| Property | Value |
|----------|-------|
| Selector | `.card-link .card, a > .card, .card[href]` |
| transform on hover | `translateY(-1px)` |
| Border on hover | `border-color: var(--color-accent-hover)` (`#4d94f8`) |
| Transition | `$transition-base` (0.15s ease-in-out) |
| Transition properties | `transform`, `border-color` |
| Default state | `transform: translateY(0)`, `border-color: var(--color-border)` |
| Layout shift | none — translateY does not affect layout flow |

The `.card` base rule in `_cards.scss` must declare `transition: $transition-base` for the lift to animate. Add hover rules to `_cards.scss` directly (collocated with existing card styles).

Clickable card definition: any `.card` that is a direct child of an `<a>` tag, or any element with class `.card-link` wrapping a `.card`.

### POLL-03 — Table Header Typography

| Property | Value |
|----------|-------|
| Selector | `.table thead > tr > th` (existing selector in `_tables.scss`) |
| `text-transform` | `uppercase` |
| `letter-spacing` | `0.05em` |
| `font-size` | unchanged (inherits 15px body) |
| `font-weight` | `600` (already set — no change) |
| `color` | `var(--color-text-muted)` (already set — no change) |

Add two properties to the existing `.table thead > tr > th` rule in `_tables.scss`. No new selectors needed.

## Component Specifications

### ButtonGlow (POLL-01)

```scss
// In _interactions.scss (new file, imported last before bootstrap-icons)
.btn-primary {
  transition: $transition-base;

  &:hover,
  &:focus-visible {
    box-shadow: 0 0 12px rgba(47, 129, 247, 0.3);
  }
}

// Include .btn-accent if the class exists in templates
.btn-accent {
  transition: $transition-base;

  &:hover,
  &:focus-visible {
    box-shadow: 0 0 12px rgba(47, 129, 247, 0.3);
  }
}
```

### CardLift (POLL-02)

```scss
// Additions to _cards.scss

.card {
  background-color: var(--color-bg-surface);
  border-color: var(--color-border);
  transition: $transition-base; // ADD: enables lift and border animations
}

// Clickable card: direct child of <a>, or .card-link wrapper
a > .card,
.card-link > .card {
  &:hover {
    transform: translateY(-1px);
    border-color: var(--color-accent-hover);
  }
}
```

### TableHeader (POLL-03)

```scss
// Addition to existing rule in _tables.scss

.table thead > tr > th {
  background-color: var(--color-bg-surface);
  color: var(--color-text-muted);
  font-weight: 600;
  border-bottom: 1px solid var(--color-border);
  white-space: nowrap;
  text-transform: uppercase;   // ADD: POLL-03
  letter-spacing: 0.05em;      // ADD: POLL-03
}
```
