Create the new file `app/assets/stylesheets/_interactions.scss` with EXACTLY the following content (preserve the leading comment header, blank lines, and indentation). Use the Write tool — do NOT use cat/heredoc.

```scss
// _interactions.scss
// Imported in application.bootstrap.scss after @import 'avatar' (Phase 5, Plan 01).
// Source-order cascade: this partial comes AFTER all Bootstrap component partials,
// so its rules win over Bootstrap's default :focus-visible box-shadow at equal specificity.
// POLL-01: button hover/focus-visible electric blue glow.

.btn-primary {
  transition: $transition-base;

  &:hover,
  &:focus-visible {
    box-shadow: 0 0 12px rgba(47, 129, 247, 0.3);
  }
}

// .btn-accent: no template currently uses this class (verified by grep).
// Included for forward-compatibility — zero current effect, takes effect the moment a template adopts the class.
.btn-accent {
  transition: $transition-base;

  &:hover,
  &:focus-visible {
    box-shadow: 0 0 12px rgba(47, 129, 247, 0.3);
  }
}
```

Critical constraints (from RESEARCH.md):
- Do NOT change `padding`, `border-width`, `margin`, or any layout-affecting property on hover. Only `box-shadow` and `transition` are allowed.
- Do NOT use `outline` instead of `box-shadow` — outline does not support blur radius.
- Do NOT use `:hover` only — the rule MUST also include `:focus-visible` for keyboard accessibility.
- Do NOT add `transition` only inside `:hover` — it must be on the base `.btn-primary` block so the leave animation works (mouseout fades the glow out instead of snapping).
- Use the literal RGBA value `rgba(47, 129, 247, 0.3)` — not `var(--color-accent)` with opacity (CSS custom properties cannot be alpha-blended without color-mix() which we don't need here).
